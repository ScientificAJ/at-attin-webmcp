**Goal:** Build and deploy a polished single-user fictional bank whose complete banking surface is available through 60 genuine WebMCP tools with an app-owned human confirmation boundary.

**Architecture:** A React and TypeScript single-page application owns a versioned device-local banking store. Manual UI actions and WebMCP handlers call the same typed domain services; the WebMCP bridge adds validation, preparation, trusted confirmation, idempotent commit, cancellation, and audit logging. The visual layer follows the approved image references and remains usable when WebMCP is unavailable.

**Tech Stack:** React, TypeScript, Vite, React Router, Zod, Lucide React, Vitest, Testing Library, Playwright, native WebMCP imperative and declarative APIs, Sites hosting

**Spec:** docs/superpowers/specs/2026-08-31-at-attin-design.md

## Global Constraints

- ATC is fictional, has no cash value, and is stored only as integer minor units.
- Credentials are exactly john.attin / attin2026 and are visibly labeled prototype-only.
- No built-in chatbot, natural-language parser, deterministic assistant, hosted LLM, remote model, real financial rail, analytics SDK, or API key.
- Exactly 60 meaningful WebMCP surfaces are discoverable after login and while Agent Access is unlocked: 56 imperative tools and four declarative tools.
- Every agent read and mutation must pause on an At Attin-owned confirmation surface before protected data is returned or state is committed.
- No WebMCP tool may approve a pending action, unlock Agent Access, or obtain a reusable approval.
- Confirmation requires a direct trusted user activation; sensitive security actions also require typing YES.
- Tools remain same-origin, register with one AbortController, unregister on logout/lock/teardown, and accept execution cancellation through the callback AbortSignal.
- Tool names remain under 30 characters, descriptions under 500 characters, parameter descriptions under 150 characters, and returned strings under 1.5K characters.
- Any tool that can return merchant, payee, note, subscription, transaction, support, or audit text sets untrustedContentHint; every pure read tool sets readOnlyHint.
- The canonical seed totals 42,860 ATC: Daily Account 8,440; Vault 24,000; Rainy Day 10,420.
- The desktop global navigation is Home, Accounts, Payments, Activity, Reports, Settings; Cards, Plan, Support, and Safety & Agent are nested routes.
- Match outputs/at-attin-design/home.png, login.png, accounts.png, payments.png, and safety-agent.png at 1487×1058.
- Meet WCAG 2.2 AA targets, 44×44 px controls, keyboard operation, visible focus, 200% zoom, reduced motion, large text, and high contrast.
- Dates in consequences and confirmations use an unambiguous day-month-name-year format, and status never relies on color alone.
- The application must remain fully usable through the manual UI when document.modelContext is unavailable.
- Use real native document.modelContext.registerTool and declarative form annotations; test doubles are allowed only in automated tests.
